# Driving Theory Test Kit Growth Audit

**Live → https://eddieatadapty.github.io/rac-theory-flow-rebuild/**

Five ideas to turn more Driving Theory Test Kit users into subscribers, each built into a clickable version of Driving Theory Test Kit's own onboarding. Prepared by Adapty.

| # | Idea | Potential outcome |
| :-- | :-- | :-- |
| 01 | Ask which test and when, then show their plan to test day | +10–20% CR to purchase |
| 02 | Let them answer real questions before you ask for £4.99 | +5–15% CR to purchase |
| 03 | Put your proof where people decide to pay | +5–10% CR to purchase |
| 04 | Size the price to their test date | +5–10% CR to purchase, fewer refund requests |
| 05 | Catch the people who close the paywall | +3–8% CR to purchase, from people who close the paywall |

Every price, rating and feature comes from Driving Theory Test Kit's App Store listing, website or in-app screens. Impact ranges are Adapty’s expected effect from teardowns and A/B tests across 30,000+ subscription apps, not measured lift for Driving Theory Test Kit. They overlap, so they don’t add up.

Static single page, no build step: `python3 -m http.server`.
